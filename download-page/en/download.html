Download Better Deen for Android

Download Better Deen (APK)

Android 7.0 or newer · about 75 MB

Before installing. If you installed a test version of Better Deen from a computer before, uninstall it first (Settings → Apps → Better Deen → Uninstall). This version is signed with another key and Android won't install it over the other one: you'd see “App not installed”.

How to install it

  1. Tap Download in Chrome or Samsung Internet. If the browser warns that “this type of file can harm your device”, choose Download anyway.
  2. Open the downloaded file. Android asks for permission to install unknown apps from that app (Chrome, My Files or Telegram): tap Allow from this source.
  3. If you see “Blocked by Play Protect”: tap More details → Install anyway.
  4. Tap Install, then Open.
Samsung: the installation is blocked

Settings → Security and privacy → Auto Blocker: turn it off while you install (you can turn it back on afterwards). Download the file from this page over Wi-Fi; a file forwarded on WhatsApp arrives damaged. “There was a problem parsing the package” means the download was incomplete: delete it and download again.

Xiaomi, Redmi, POCO

In the Security app → settings, turn off Scan before installing, and allow your browser or file manager to install unknown apps.

After installing

Allow notifications and, on Android 14 or newer, alarms and reminders, so the adhan sounds on time. For the widgets: Tools → Home screen widgets.
